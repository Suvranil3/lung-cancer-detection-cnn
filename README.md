# Lung Cancer Detection using CNN

## 📌 Project Overview
This project uses Deep Learning and Convolutional Neural Networks (CNN) to detect lung cancer from CT scan images.

The model classifies CT scan images into:
- Normal
- Cancer

The project was developed as a Final Year Project for B.Tech AIML.

---

## 🧠 Technologies Used
- Python
- TensorFlow
- Keras
- OpenCV
- NumPy
- Matplotlib
- Google Colab

---

## 📂 Dataset
Dataset used:
- LIDC-IDRI CT Scan Dataset

Images were preprocessed using:
- Resizing
- Normalization
- Data Augmentation

---

## ⚙️ Model Architecture
The CNN model contains:
- Convolution Layers
- Max Pooling Layers
- Dropout Layers
- Dense Layers

Optimizer used:
- Adam Optimizer

Loss Function:
- Binary Crossentropy

---

## 📊 Model Performance
- Test Accuracy: ~75%
- Precision, Recall and F1-score used for evaluation
- Confusion Matrix generated for analysis
